# Terra Analog

**Earth-Moon-Mars Analog Site Finder**
*NASA Space Apps Challenge 2026*

## Overview
A similarity search over Earth. Pick a target (Moon or Mars site), and the tool scores every Earth grid cell against it on physical criteria, ranks the best analogues, and shows the rationale criterion by criterion.
